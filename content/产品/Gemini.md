## 一、发展脉络与创始人基因

### 创始团队的"多元科学家"基因

**Demis Hassabis** — [CEO DeepMind](https://www.cnbc.com/2026/01/16/deepmind-google-ai-competition-demis-hassabis.html)
- 游戏设计师 × 神经科学家 × AI 研究者的跨学科组合
- 2010年创办 DeepMind，2014年被Google收购
- 2023年与Google Brain合并后，成为Google AI的"引擎室"(engine room)
- 核心哲学："World Models"不是"Language Scaling"

**Jeff Dean** — Chief Scientist
- Google资深科学家，主导Google Brain发展十余年
- 兼任Google DeepMind科学总顾问

**Sundar Pichai** — [CEO Alphabet](https://www.cnbc.com/2026/01/16/deepmind-google-ai-competition-demis-hassabis.html)
- 与Hassabis"每日沟通协作"，信号：Google把AI视为最高战略优先级

### 组织演进：从研究到产品的"距离缩短"

| 时间 | 事件 | 战略意义 |
|------|------|---------|
| **2023年4月** | DeepMind + Google Brain 合并为Google DeepMind | 消除AI研究的组织孤岛 |
| **2024年10月** | Gemini 产品团队转移到DeepMind | 研究、模型、产品三合一，"扩大容量"而非流程优化 |
| **2024年12月** | 启动"World Models"研究方向 | Hassabis独辟蹊径，放弃"text scaling"竞争 |

**非共识判断**：Google 在做"系统设计"，消除了传统的研究→工程→产品的传送带延迟。这在AI时代意味着每个新capability可以在6周内从论文到用户手中。

## 二、成长旅程

### 2.1 冷启动：仓促应对(2023年3月-12月)

**背景**：[2022年12月"Code Red"](https://9to5google.com/2022/12/21/google-code-red-chatgpt/)

ChatGPT上线后，Google CEO Sundar Pichai宣布"code red"。跨Research、Trust & Safety、产品部门人员重新编制。

**Bard上线**(2023年3月)
- 质量有问题，股价下跌
- 仓促之作，但完成了从"没有产品"到"有产品"的跨越

**Gemini 1.0上线**(2023年12月)
- 首次推出三个模型规格：Ultra(最强) / Pro(均衡) / Nano(轻量)
- 多模态支持(文本、图像、音频、视频)
- 战略调整：放弃"追赶ChatGPT的文本能力"，转向"覆盖更多使用场景"

## 三、战略框架

### 3.1 核心战略：生态粘合剂，而非单点AI产品

**Google的真实目标**：不是"打败ChatGPT"，而是"让用户离不开Google"

```
Search (5B 日活)
    ↓
Android (10亿+ 设备)
    ↓
Workspace (数百万企业)
    ↓
Project Astra (眼镜，2026年起)
    ↓
= Gemini 是跨这些产品的统一对话界面
```

**vs 竞争者**：
- ChatGPT = "最好的单点AI产品"
- Gemini = "最难替代的AI生态"

[来源](https://deepmind.google/blog/announcing-google-deepmind/)

### 3.2 "距钱距离"假说的应用

Google AI变现的三层金字塔：

| 层级 | 商业模式 | 规模 | 战略优先级 |
|------|---------|------|----------|
| **第1层(距钱最近)** | 广告(Search AI Mode) | 2B+ 月活 | P0(最优先) |
| **第2层** | 订阅 + 企业套件 | 10-50M 付费用户 | P1(重要) |
| **第3层(距钱最远)** | API / Vertex AI | 数万开发者 | P2(优化) |

**非共识判断**：Gemini订阅($20/月)看起来规模大，但**广告**才是真正的金矿。

- Search AI Mode 广告变现：从2025年开始，已在$63.07B搜索收入中体现
- YoY增速：+17%，其中10-17%由AI驱动
- 潜力：如果渗透到Gemini App本身，可能再增加10-20B年收入
- [来源](https://almcorp.com/blog/google-search-63-billion-ai-mode-advertising-q4-2025/)

### 3.3 增长飞轮结构

```
Google 生态入口 (Search 5B日活 + Android 10亿设备)
    ↓
Gemini AI 赋能 (搜索摘要、Workspace写作、Android助手)
    ↓
用户粘性提升 (更长使用时间、跨应用数据依赖)
    ↓
广告 + 订阅变现 (更高ARPU、企业锁定)
    ↓
投资更多 CapEx (更强AI能力、新硬件研发)
    ↓
飞轮闭环：能力 → 用户 → 收入 → 投资
```

**飞轮的关键特性**：
1. **冷启动优势**：不需要"获客"，从Search/Android现有用户开始
2. **复合变现**：不依赖单一模式(订阅)，而是广告+套件+API多元化
3. **正反馈强度**：每个新功能都让Google生态更难被替代

[来源](https://almcorp.com/blog/google-gemini-vs-chatgpt-market-share-2026/)

## 四、蓝图复刻

### 如果你想复刻Gemini，需要具备：

**硬件前置**
- 不是"从App开始"，而是"从终端入口开始"
- 实现方案1：已有搜索/社交/视频等高频产品 → 嵌入AI
- 实现方案2：自建交互硬件(手机、眼镜、汽车) → 预装AI
- 难度：需要超级平台公司(Alphabet, Meta, Apple)或资本压制优势

**生态融合**
- 不是"单一Copilot"，而是"跨多应用的协调"
- 示例：Gmail信息 + Drive文档 + Calendar事件 → 一句话生成周报
- 难度：需要API集成权限 + 用户数据权限

**变现多元化**
- 优先级：广告(最近) > 企业套件 > 订阅 > API
- 千万不要"依赖订阅"，那是"利息"，不是"本金"
- 难度：广告需要10亿+用户、企业套件需要销售网络

**资本耐心**
- CapEx支撑：Google 2026年$175-185B(vs OpenAI~$100B)
- 允许长期补贴用户成本，快速占据市场
- 难度：需要现金流充沛的上市公司或融资超级轮

**组织效率**
- 消除"研究→产品"的传送带延迟
- Google通过"合并DeepMind和Gemini团队"做到
- 难度：需要跨学科的领导力(Hassabis模式)

## 六、Mars 视角

### 观点1：Google 在做"平台包围圈"，不是"产品竞争"

**现象**：Gemini 750M用户，ChatGPT 810M用户，但Gemini增速远快

**本质**：不是"产品更好"，而是"产品无处不在"

- Android预装 → "选择权"被动失效
- Search AI Overviews → 流量被截取(用户无法避免)
- Gmail/Drive → AI功能原生，切换成本提升

**创业启示**：
- 如果你的AI不能"嵌入高频产品"，用户获取成本会被压制3-5倍
- 反过来：存在**某个高频入口的创业者**(输入法、日程、即时通讯)，AI赛道可能是"降维打击"
- 最安全做法：控制**交互终端**，而非应用层

### 观点2：Demis Hassabis的"World Models"是下一个制高点

**现象**：2024-2025所有团队都在"scaling laws"(参数堆积)，Hassabis说"这错了"

**本质**：
- Language Models = 模式识别(相关性)
- World Models = 因果推理(因果性)
- Project Astra = 世界模型在眼镜/机器人上的应用

**创业启示**：
- 如果你的AI能"理解因果"(不只是相关性)，可能突破语言模型天花板
- 应用场景：工业制造(机器人学物理规律)、自动驾驶(预测世界演化)、科学发现(反推模型)
- 难度：需要数据 > 参数(Hassabis的核心观点)

[来源](https://www.humanoidsdaily.com/news/deepmind-world-models-infinite-training-loops-agi)

### 观点3：Google 的资本优势是绝对压制

| 维度 | Google | OpenAI | 含义 |
|------|--------|--------|------|
| 2026年CapEx | $175-185B | ~$50-100B | Google可烧钱做基础设施，OpenAI需立刻变现 |
| 年营收 | $307B | ~$80B(推估) | Google可补贴AI，OpenAI不能 |
| 现金流 | $150B+ | $30B+ | 时间换空间的能力完全不同 |

**含义**：Google可以"长期补贴AI用户获取"，OpenAI需要"快速找到变现"。这导致完全不同的产品哲学。

[来源](https://fortune.com/2026/02/04/alphabet-google-ai-spending-supply-constraints/)

### 观点4：Workspace 是被严重低估的护城河

**现象**：Google Workspace有数百万企业用户，Gemini集成 = "免费升级"到AI助手

**护城河深度**：
- 企业切换成本高(数据、工作流迁移)
- Gemini in Workspace = 不需要额外销售，自动推送给现有客户
- 协作数据(邮件、文档、日历) = Gemini最强大的上下文

**非共识**：B2B的客户锁定能力 > B2C的网络效应。一个100万Workspace企业用户，比1亿消费者App价值更高。

### 观点5：硬件是最后一公里

**现象**：Google做眼镜，Apple做Vision Pro，Meta做Ray-Bans

**本质**：终端形态决定"AI入口权"
- 手机时代 = App Store + Android之争
- 眼镜时代 = 谁的OS/谁的入口 = 谁垄断对话界面

**创业启示**：
- "应用层AI"(Copilot for X)长期风险很高，因为平台可以轻易替换
- "交互终端控制者"(眼镜、机器人、汽车)价值链在手上
- 最安全做法 = 某个垂直领域的"完整系统"(硬件+软件+AI)，难被平台替代
- 例：医疗扫描眼镜(硬件+AI)比"医疗AI软件"难被挤压

## 七、相关案例

### 类似的"生态粘合剂"战术

**案例1：Android + Google Play**
- 入口：10亿设备预装
- 粘合：搜索、地图、YouTube、邮件
- 变现：广告 > 应用内购 > API
- 教训：平台预装 > 用户主动下载

**案例2：Windows + Office**
- 入口：企业PC预装
- 粘合：Word、Excel、Outlook、Teams
- 变现：企业套件 > 云存储 > API
- 教训：控制企业生产力链路 = 垄断

**案例3：微信 + 小程序 + 支付**
- 入口：10亿日活
- 粘合：支付、社交、内容、商业
- 变现：广告 > 支付手续费 > API
- 教训：对话界面 + 支付 = 不可替代的入口

**Gemini的相似性**：
- 入口：搜索、Android、Workspace
- 粘合：AI助手成为跨应用的统一界面
- 变现：广告 > 订阅 > API
- 长期目标：眼镜成为新的"入口"(如iPhone之于手机)
