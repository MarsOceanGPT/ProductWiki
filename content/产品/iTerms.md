# iTerms v4.0 产品卡片

## 产品概览

**产品名称**：iTerms（一站式法律AI工作台）
**母公司**：法大大
**定位**：面向法务团队、律师事务所和企业法学部门的AI驱动的法律全流程工作平台
**核心价值**：通过大模型驱动的合同智审、法律研究、知识库等功能，将法律工作从体力活转变为智力活，把50%的重复性法务工作还给AI

---

## 问题域(Problem Space)

### 传统法律工作的痛点

1. **合同审查效率低下**
   - 手工审查一份合同平均需要30-60分钟，反复对标条款浪费时间
   - 风险遗漏率高：容易漏掉隐藏的法律陷阱、支付条件不合理、保密义务不足等问题
   - 标准化程度不足：同样的合同类型每次都要从零开始

2. **法律人力资源紧张**
   - 500强企业平均每个法务人员处理合同数量过多（月均50+份），时间压力大
   - 初级法务和有经验法务的工作效率悬殊，难以规模化
   - 重复性工作占比高：提取关键信息、比对条款、生成报告等工作可标准化

3. **法律知识获取分散**
   - 法律检索需要在多个数据库之间切换（案例库、法规库、法律文库等）
   - 法律咨询响应慢：需要等待专业律师或法学部门回复
   - 内部知识难以沉淀：企业级的合同范本库、风险库、决策记录分散在邮箱和本地文件中

4. **协作流程割裂**
   - 合同审查需要多部门协同（业务、财务、法务），但现有工具无法同步协作
   - 修改意见追踪困难：版本众多，难以追踪谁修改了什么、为什么修改

## 解决方案(Solution Architecture)

### 核心功能矩阵

#### 1. AI合同智审（Contract Intelligence）
**核心价值**：秒级完成合同风险识别和修改建议

- **智能风险识别**
  - 多维度风险扫描：违约责任不清、支付条件不合理、保密义务不足、知识产权条款缺失等10+类风险
  - 精准定位：不仅指出有风险，还用高亮和引用精确定位到具体条款文本
  - 一键生成合同摘要：自动提取合同双方、金额、有效期、支付方式等关键要素

- **智能建议和修改**
  - 条款改写：AI基于法律最佳实践给出具体的改写建议，不仅是"这里有风险"，而是"可以改成这样"
  - 对标模板：将合同与标准模板自动对标，快速定位差异项
  - 多轮对话：用户可进一步追问："为什么这里有风险？""如何修改能更保险？"等

- **效率提升**
  - 合同审查时间从30-60分钟降至3-5分钟（提升90%）
  - 覆盖率从80%提升至95%+（不遗漏隐藏的坑）
  - 支持批量处理：可同时处理数十份相同类型的合同

#### 2. 法律研究助手（Legal Research）
**核心价值**：秒级精准检索，替代传统法律数据库的手工查询

- **海量数据支撑**
  - 15亿+司法案例库（全国法院判决书、裁定书）
  - 470万+法律法规库（国家法规、地方法规、行业规定等）
  - 实时更新：重大法律变化（新法落地、高法释义等）及时同步

- **智能语义检索**
  - 自然语言输入：用户可用口语化表述问题，无需掌握法律专业术语
  - 语义相似度匹配：不是关键词匹配，而是理解问题的本质意思后检索相关案例和法规
  - 关联推荐：检索到相关判例后，自动推荐同类案件、类似条款的其他法规等

- **法律研究工作流**
  - "看不懂这条合同条款？问一下"：用户上传合同条款，AI解读含义、检索相关法规和案例
  - "遇到类似纠纷案件？找判例"：输入案件特征，检索相关判决书和处理逻辑
  - "新政策出台了？关键条款梳理"：法律更新后，AI自动梳理对企业的影响

#### 3. 法律咨询助手（Legal Consultation）
**核心价值**：7×24小时秒级法律咨询，替代人工咨询的首轮筛查

- **通用法律问答**
  - 支持企业法务、HR、商务等常见法律问题的Q&A
  - 回答质量可控：基于法规库 + 判例库 + 企业知识库的三层验证
  - 多轮对话：支持深度追问，回答更精准

- **企业知识库集成**
  - 内置企业级的合同范本库、风险库、决策记录库
  - "按照我们公司的标准怎么处理？"→ 检索企业历史案例和决策，给出一致性建议
  - 知识库不断积累：每个合同审查、每个法律决策都沉淀为企业知识

#### 4. 全流程协作（Collaboration）
**核心价值**：打通合同从起草→审查→签署→履行的全链条，实现多角色协同

- **实时多人协作**
  - 同步编辑：业务、财务、法务等多个角色可同时在线编辑合同
  - 角色权限管理：可定制不同角色的编辑/查看权限
  - 修改追踪：变更追踪清晰，知道谁改了什么、什么时候改的、为什么改

- **智能流程控制**
  - 自定义审批流：定义合同额度、合同类型的对应审批链条
  - 智能提醒：合同到期前自动提醒续签，付款期限前提醒财务
  - 全生命周期管理：从草稿→一审→二审→签署→履行→存档的全链条可视化

#### 5. 知识库系统（Knowledge Base）
**核心价值**：将企业法律资产数字化、标准化、可复用

- **范本库管理**
  - 企业级合同范本：建立分类的、版本化的合同范本库
  - 快速生成：新合同可基于范本一键生成，修改参数即可
  - 范本更新追踪：法律变化时，可批量更新相关范本

- **风险库和决策记录**
  - 行业风险库：沉淀企业在各类合同中遇到的常见风险和处理方案
  - 决策记录：企业对某类风险的处理决策可记录，形成企业级的法律判例库

## 市场现状与竞争

### 目标市场规模

**法律科技赛道在2025-2026年的三大机遇**

1. **从流程自动化到智能决策**
   - 以前的legal tech是"帮助提高效率"（数字化合同、电子签署等）
   - iTerms代表的新一代是"辅助决策"（AI帮你分析风险、给出建议），这才是真正的价值所在
   - 市场空间：从"提效20-30%"升级到"减少工作50%+，降低风险20-30%"

2. **内外部法律服务市场的融合**
   - 大型企业在减少外部律师费用，转向内部建设（"in-house counsel"趋势）
   - iTerms通过AI弥补内部法务水平差异，可以用2个人做5个人的工作
   - 机会：替代律师事务所的初审/基础咨询服务

3. **从点工具到平台化**
   - 合同审查只是切口，真正的机会在"全流程法律工作台"
   - 整合合同 → 法律检索 → 协作 → 决策记录 → 知识沉淀，形成企业法律资产
   - 粘性提升：从"用一个功能"升级到"离不开这个工作台"

### 竞争格局

#### 直接竞争对手
- **法智（Fazhi）**：专注AI合同审查，功能相似，用户规模较小
- **AlphaGPT**：法律领域通用AI，功能广泛但深度不足
- **智合同**：合同管理 + AI能力，但企业级集成能力弱

#### 间接竞争对手
- **传统律师事务所**：人工法律咨询和审查（成本高、速度慢）
- **通用法律数据库**：北大法宝、eLegal等（检索能力强但无AI能力）
- **企业OA系统内的法律模块**：钉钉/企业微信的内置法律工具（功能浅）

#### iTerms的竞争优势
1. **母公司背景**：法大大是国内最大的电子合同SaaS平台（已服务200+Fortune500），自带客户基础和数据优势
2. **数据密度最高**：15亿+案例库 + 470万+法规库，这是AI模型训练和推理的基础
3. **企业级能力**：不仅是"聊天机器人"，而是可集成、可部署、可定制的企业级工作平台
4. **垂直深度**：长期积累的法律领域专业知识，而非通用LLM的泛化能力

## 本质洞察

### iTerms代表的三层价值递进

#### 第一层：工具价值（Tool）
"用AI替代人工审合同"→ 提升效率30-50%，但用户感知有限

#### 第二层：能力价值（Capability）
"用AI建立企业级的法律决策能力"→ 通过知识库沉淀、范本库积累，让企业的法律能力不再依赖个人经验
本质上是："从人依赖"转为"系统依赖"

#### 三层：战略价值（Strategic）
"重构企业法务的价值链"→ 从"法务 = 风险防控"升级为"法务 = 商业赋能"
- iTerms让法务团队有更多时间做战略法律顾问，而不是埋头处理合同
- 反过来说，这是法务部门从"成本中心"向"利润中心"的转变

**距钱距离分析**：
- iTerms的直接价值：替代律师费用 + 节省法务人工成本（距钱很近）
- 但更大的价值在"法务赋能商业决策"（距钱远，但长期价值更大）
  - 比如：一份合同风险识别，可能避免的损失是"AI审查成本"的1000倍
  - 比如：企业内部的法律知识库，是企业核心资产，可用于风险管理、商务谈判等

### 为什么现在？为什么是iTerms？

1. **AI时机成熟**
   - 通用LLM（ChatGPT、Claude等）的出现，法律领域不再需要专有模型
   - iTerms的价值 = 法律数据库（自有）+ 通用LLM（OpenAI/Open Source） + 垂直产品体验
   - 而不是从零开始训练法律模型

2. **法律从业者的痛点达到临界**
   - 合同量和合同类型爆炸增长（电商、SaaS、跨境等）
   - 法务团队编制没有增长，但工作量翻倍
   - "我们需要AI"已经从奢侈品变成刚需

3. **法大大的平台优势**
   - 电子合同的市场领导者，拥有数亿份真实合同数据
   - 这是iTerms无法被复制的护城河（数据越多 → AI越聪明 → 网络效应越强）

### 反共识观点

**主流观点**："AI会取代律师"
**iTerms代表的不同思路**："AI会改变律师的工作方式，而不是取代"
- 律师事务所面临的真正威胁不是AI，而是"内部法务崛起" + "AI降低咨询成本"
- iTerms的商业机会在于：为企业内部法务赋能，让他们能处理更多、更复杂的法律工作
- 对律师的威胁 ≠ iTerms的威胁，反而律师可以用iTerms来提升竞争力
