# Jan Zoltkowski

> 这个人最值得记住的是：他用黑客的思维赢了一场『监管之战』——不是对抗，而是用技术结构让监管无能为力。

## 身份与背景

澳大利亚黑客，HackerOne 和 EthGlobal 的多次获奖者。这说明什么？他是那种"在技术竞赛中打败别人"的人。黑客文化意味着：他对规则的边界有天然的灵敏度。

### 创业故事：周末项目的爆炸

2023年6月，Zoltkowski 花了一个周末，用开源 LLM 拼出了 **Janitor AI**——一个"AI 角色聊天"的应用。定位完全是开放的（你懂的），用户基数瞬间爆炸。

**不公平优势**：技术足够强硬（能自建 LLM） + 极度隐形（规避监管） + 懂加密文化（吸收不怕监管的用户）。

### 关键危机：OpenAI 的 C&D

2023 年底，Janitor AI 因为使用 OpenAI API 被律师函（Cease and Desist）。

**普通创业者的反应**：惊慌、寻求融资、改产品定位

**Zoltkowski 的反应**：24小时内自建了 [[JanitorLLM]]，完全绕开对 OpenAI 的依赖。

这不是"临时方案"，而是核心能力的展现——他足够强硬，可以独立迭代。

## 关键决策与产品

### 决策1：用户自带 API Key

这是 Zoltkowski 的"监管破招"。用户用自己的 OpenAI key，所有成本由用户承担，Janitor AI 只赚中间的 margin 和 premium tier。

**效果**：
- 用户自己为 API 付费（不违法）
- Janitor AI 的法律风险接近零
- 边际成本为零（纯 margin 业务）

### 决策2：极度隐形

CEO 几乎没有 Twitter 账号，没有公开演讲，没有参加 YC。

这在 AI 创业者中极其罕见。但对 NSFW 市场来说，隐形是生存技巧。避免了品牌争议和监管聚焦。

### 决策3：$3M 融资，保持控制权

融资规模很小（Sky9 Capital + North Equity），这意味着 Zoltkowski 保持了完全的掌控权，不需要向任何 VC 汇报"我们应该怎样做"。

## 产品 DNA

[[Janitor AI]] 的核心特征是**完全透明化的成本结构**。用户看得见自己在花钱，付款流向也清晰。

这反而成了 NSFW 平台最大的信任来源——没有暗箱操作，就没有监管漏洞。

产品设计很极简：角色库、聊天、可定制模型。没有花哨功能，专注于"对话质量"。

## 思想特征

### 核心洞见1：隐形本身就是产品策略

大多数 AI 创业者认为"曝光率"很重要。Zoltkowski 认为对 NSFW 市场，隐形才是竞争力。

### 核心洞见2：透明成本结构 = 防监管护城河

违法产品害怕监管。但完全透明的成本结构无法被监管定罪。
