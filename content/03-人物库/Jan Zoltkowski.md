# Jan Zoltkowski

> 这个人最值得记住的是：他用隐形人策略，把一个"监管地雷"的市场做成了参考级的增长标本。

## 背景

澳大利亚黑客。这不是夸张——HackerOne 和 EthGlobal 的多次获奖者，说明他就是那种"在技术竞赛中打败别人"的人。黑客松文化和加密工程背景意味着：他对规则的边界有天然的灵敏度。

2023年6月，作为一个黑客松项目，他用一周末时间拼出了 Janitor AI——一个"AI 角色聊天"的应用，定位完全是开放的（你懂的），用户基数瞬间爆炸。

**不公平优势**：技术足够强硬（能自建 LLM）+ 极度隐形（规避监管和品牌破坏）+ 懂加密文化（吸收了不怕监管的用户群体）。

## 关键决策

- **OpenAI API 被 C&D 后，24小时自建 JanitorLLM**：展现出硬核技术能力。不依赖任何大厂，可独立迭代。这是打赢监管之战的必要条件
- **开放用户自带 API Key**：反而让平台的边际成本为零。用户自己烧钱用自己的 OpenAI key，Janitor 只赚中间的 margin 和 premium tier。这是"零风险的盈利模式"
- **极度隐形：CEO 几乎没有 Twitter 账号，没有公开演讲**：这在 AI 创业者中极其罕见。但对 NSFW 市场来说，隐形反而是生存技巧。避免了品牌争议和监管聚焦
- **$3M 融资（Sky9 Capital + North Equity）**：初创公司验证了 NSFW AI 品类的商业可行性，但融资也保持低调

## 产品 DNA

[[Janitor AI]] 的核心特征是**完全透明化的成本结构**。用户看得见，用的是自己的 API key，付款流向也清晰。这反而成了 NSFW 平台最大的信任来源——没有暗箱操作，就没有监管漏洞。

产品本身做的很极简：角色库、聊天、可定制模型。没有花哨功能，专注于"对话质量"。这个克制反而让它在 1.38 亿月访问的体量下，保持了高粘性。
