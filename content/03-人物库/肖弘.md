# 肖弘

> 这个人最值得记住的是：他用『kitbashing 哲学』（快速组装最好的开源模型），在 AI Agent 这个新品类上做了第一个完整产品。9 个月 $125M run rate，用最短时间完成了 mega exit。

## 身份与背景

1992 年生，江西吉安人，华中科技大学软件工程 2015 届。

与其说是"天才"，不如说是"执行机器"——从大学时期就开始连续创业，一个项目接一个项目，每个都赚钱或获得资本认可。

### 第一阶段：校园工具（2015-2016）

- **壹伴助手**（WeChat 公众号管理）：获得真格基金投资
- **微班助手**（教师教学工具）：200 万用户，被明略科技收购

这两个产品说明了什么？他有"从零到规模"的能力。

### 第二阶段：浏览器生态（2022-2024）

**[[产品卡片-Monica|Monica]].ai**（[[产品卡片-ChatGPT|ChatGPT]] for Chrome）：用一个"把 [[产品卡片-ChatGPT|ChatGPT]] 集成到浏览器里"的简单想法，做到：
- 1000 万用户
- $10M ARR

**关键决策**：在最容易获得融资的阶段，拒绝了 ByteDance 的 $30M 收购要约。这个"Say No"很重要——他知道应该坚持什么。

### 第三阶段：Agent 革命（2025）

**[[产品卡片-Manus|Manus]].im**（通用 AI Agent）：

**2025年3月发布**，9 个月达成 $125M run rate。

**2025年12月**，Meta 以 $2-3B **完全收购**，肖弘成为 Meta VP。

---

## 关键决策

### 决策1：[[产品卡片-Monica|Monica]] → [[产品卡片-Manus|Manus]] 的战略转折

2024 年底，肖弘做了最大胆的决定——砍掉已经有 1000 万用户、$10M ARR 的 [[产品卡片-Monica|Monica]]（浏览器插件），全力转向 [[产品卡片-Manus|Manus]]（AI Agent）。

这很疯狂。但他看穿了：

> **浏览器插件的天花板是『助手』，真正的机会是『Agent』——能够自主规划和执行任务**

### 决策2：『Kitbashing』哲学的实践

[[产品卡片-Manus|Manus]] 的技术不是"从零发明"，而是快速组装最好的开源模型、推理框架、API。

用 80% AI 生成的代码（他自己用 AI 写代码），最快速地验证市场。

这是对"从头打造完美产品"的否定。

### 决策3：0 广告投入的增长

[[产品卡片-Monica|Monica]] 时代就是"零营销"，[[产品卡片-Manus|Manus]] 也是。完全靠产品口碑和社区传播。

> **产品足够好就不需要花钱买量**

### 决策4：流量最贵时的 Copycat 思维

2024-2025 年，AI Agent 概念最火，竞争最激烈。肖弘不是"创造新品类"，而是"快速做出最好的参考实现"。

反而成了标杆。

## 产品 DNA

[[Manus]] 的设计哲学反映了肖弘整个创业风格：**让用户有一个『自主的 AI 助手』，不需要手把手教**。

与 [[产品卡片-Monica|Monica]] "你问它答"的被动模式不同，[[产品卡片-Manus|Manus]] 是"你说目标，它自主规划执行"：

**输入**："帮我规划一个周末旅游"
**[[产品卡片-Manus|Manus]] 自主**：搜索目的地 → 查找航班 → 预订酒店 → 生成行程
**输出**：完整的行程方案

这个模式需要：
1. **多步推理**：不是一次 API 调用，而是多轮思考
2. **工具调用**：集成浏览器、地图、支付等生态
3. **错误恢复**：中间某个步骤失败了，能自动 fallback

肖弘的"kitbashing"体现在：这些能力他都没自己发明，而是快速组装了 [[产品卡片-Claude|Claude]]、GPT-4、开源框架等最好的组件。

## 核心哲学：应用层 > 基础层

肖弘在多次演讲中强调的一个论点成了他的哲学：

> 基础模型公司 = 芯片制造商（高通）
> AI 应用公司 = 消费电子公司（苹果）
>
> 可持续利润率永远在应用层，不在基础层

这个论点解释了为什么：
- 他从 [[产品卡片-Monica|Monica]]（应用）到 [[产品卡片-Manus|Manus]]（更大的应用），而从不做模型
- Meta 愿意用 $2-3B 收购他——相比 OpenAI 烧钱训练模型，收购一个"Agent 第一名实现者"更有 ROI

---

## 思想特征

### 核心洞见1：『快速组装 > 从零发明』

大多数创业者认为"我要自己发明一个更好的模型"。肖弘认为"我要最快速地组装现有最好的东西"。

### 核心洞见2：『应用创新 > 基础研究』

硅谷喜欢追捧"深度科学"。肖弘追捧"深度用户理解"。

### 核心洞见3：『拒绝诱人的机会』

[[产品卡片-Monica|Monica]] 时期拒绝 ByteDance 的 $30M。这需要信念——他知道 Agent 时代即将到来，[[产品卡片-Monica|Monica]] 只是过渡。
