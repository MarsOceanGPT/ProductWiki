## 模块一：战略原点

### 非共识判断

**当时的共识**："AI 内容平台必须严格过滤 NSFW 内容，否则品牌受损、投资受阻、监管会杀死你。Character.ai 的内容审核是正确策略。"

**Janitor AI 的非共识**："**Character.ai 的 NSFW 审核不是'正确策略'，而是'主动放弃了收入最高的用户群'。** NSFW 用户的付费意愿是 SFW 用户的 10 倍，而大公司永远不会进来抢——你的竞争对手的自我设限就是你的护城河。"

这个判断的本质是：**在其他人看到风险的地方看到机会。** 主流 AI 公司（Character.ai、ChatGPT、Replika）都在做内容安全，这是正确的道德选择——但从商业角度看，它创造了一个被故意留空的巨大市场。

### JTBD 与价值再定义

**核心用户画像**：70% 女性。这是整个案例最反直觉的数据点。

**旧认知**："NSFW AI = 男性色情需求"
**真实 JTBD**：

1. **BL / 乙女 / 言情创作**：女性用户把 Janitor AI 当成"交互式小说写作工具"——创建角色、设定情节、与角色"共写"故事。这和 AO3、Wattpad 等女性主导的同人写作社区是同一个需求脉络。
2. **情感陪伴的"安全空间"**：不被算法打断、不被内容审核突然冻结——"无条件的互动自由"。Character.ai 的审核经常在对话高潮时打断用户（弹出安全警告），这对沉浸式体验是毁灭性的。
3. **创意自由**：不是"色情"，是"不受限制的角色扮演"——很多内容是暴力、恐怖、悬疑等 Character.ai 也会屏蔽的非色情但"敏感"的内容。

**价值再定义**：Janitor AI 没有发明新技术——它发明了一种 **"许可结构"（permission structure）**：让用户可以做他们一直想做但被阻止的事。这个"许可"本身就是核心价值。

**"Day 1 Advantage"**：
- Character.ai 2022 年的爆发完成了全部的用户教育——"AI 角色对话是好玩的"已经是共识
- Character.ai 的 NSFW 封禁驱赶出大量活跃用户——他们在 Reddit 上公开抱怨，等于免费的需求验证
- 黑客松出身 = 极快的产品迭代速度，不追求完美追求可用

## 模块二：早期破局

### MVP 的反直觉取舍

**做了什么**：Character.ai 的核心体验（角色创建 + AI 对话 + UGC 角色库）+ 允许 NSFW。

**故意不做什么**：
- ❌ 不做内容审核 AI（核心差异化就是"不审核"）
- ❌ 不做移动端 App（NSFW 内容在 App Store 寸步难行，只做 Web）
- ❌ 不做多模态（不做语音/图像/视频，只做文字对话）
- ❌ 不做品牌营销（NSFW 平台做品牌是给自己找事）

最反直觉的取舍：**不自建模型，让用户接入自己的 API Key**。这看似是技术短板的妥协，实际是天才设计——
1. 免费层用户的推理成本由用户自己承担（OpenAI/OpenRouter 的 Key）
2. 平台的边际成本趋近于零
3. "API Key 用户"是最高粘性的用户（他们投入了技术配置的时间成本）

### 滩头阵地

切口是 **"Character.ai 的流失用户"**——一个精确定义的、高度集中的、已经被教育好的用户群。

这个切口的战略价值：
1. **需求已验证**（Character.ai 做了所有的用户教育）
2. **获取成本极低**（Reddit r/CharacterAI 和 Discord 里充满了抱怨 NSFW 封禁的帖子——直接去捞人）
3. **转化率极高**（用户不需要被说服"AI 角色对话好玩"，只需要知道"这里不封 NSFW"）
4. **传播性强**（"终于有个不封的了"是天然的口碑传播点）

### OpenAI 禁止函：濒死体验 → 技术自主

**2023年7月**，Janitor AI 上线仅一个月，OpenAI 就发来 cease-and-desist——因为 Janitor AI 违反了 GPT API 的内容使用条款（禁止生成色情内容）。

**API 访问被切断**——这对一个 100% 依赖 OpenAI API 的产品来说是灭顶之灾。

Jan Zoltkowski 的应对：
1. **紧急采购数百块 GPU**，开始训练 JanitorLLM
2. **同时开放"用户自带 API Key"功能**——让用户用自己的 OpenAI 或 OpenRouter Key 接入，绕过平台层面的 API 限制
3. **JanitorLLM 上线**：Transformer 架构，8K 上下文，两阶段训练（通用文本预训练 → 角色扮演微调），免费、无过滤

这个"濒死体验"反而让 Janitor AI 变得更强：
- 技术自主：不再受任何 API 提供商的内容政策约束
- 成本结构：JanitorLLM 免费提供 = 极低用户获取门槛
- 差异化：**JanitorLLM 的"无过滤"特性成为核心卖点**

这是经典的"约束催生创新"——和 DeepSeek 因芯片制裁发展出 MoE 效率优势的逻辑完全一致。

### 数据飞轮冷启动

冷启动策略极聪明：**UGC 角色 = 零成本内容供给**

```
第一批用户（Character.ai 流失者）→ 带着他们在 Character.ai 创建的角色设定来到 Janitor AI
  → 在 Janitor AI 上重建角色（供给端自动填充）
  → 新用户被角色库吸引（热门角色有数百万次对话）
  → 新用户也创建角色 → 库越来越大 → 循环
```

角色库的增长不需要平台投入任何内容成本——**用户就是内容生产者**。

## 模块三：增长飞轮

### 增长引擎

完全是 PLG + Community-Led Growth 的混合。

**最关键的一个增长动作**："TikTok 上的角色扮演截图"

TikTok 是 Janitor AI 的核心增长渠道——不是官方账号（NSFW 平台不可能做官方 TikTok），而是用户自发分享有趣/惊艳/搞笑的 AI 对话截图。这些截图有强烈的"禁忌感"加持：分享"不应该看到的东西"的社交货币价值远高于"正常的 AI 对话"。

```
用户与角色的精彩对话 → 截图/录屏 → 发 TikTok/Reddit/Discord
  ↓
围观者好奇（"这是什么？在哪？"）→ 注册 Janitor AI → 创建/使用角色
  ↓
产出更多精彩对话 → 分享 → 更多新用户 → 循环
```

### 增长飞轮

```
更多用户 → 更多 UGC 角色 → 角色库更丰富 → 吸引更多用户
    ↑                                              ↓
对话质量提升 ← JanitorLLM 训练数据增加 ← 更多对话数据
```

**飞轮加速器**：Character.ai 的每一次 NSFW 审核收紧，都给 Janitor AI 送来一波新用户——**竞品的"道德升级"是 Janitor AI 的增长催化剂**。

### "寄生"策略

**对 Character.ai 的寄生**：Janitor AI 的整个存在都是寄生于 Character.ai 的内容审核政策。如果 Character.ai 开放 NSFW，Janitor AI 的核心差异化消失。但——Character.ai 已经被 Google 收购（$2.7B 授权协议），Google 品牌不可能允许 NSFW，所以这个"寄生"是安全的。

**对开源 LLM 生态的寄生**：JanitorLLM 的底层能力来自开源模型社区。随着 Llama/Qwen 等开源模型持续进步，JanitorLLM 的上限也在提高——不需要自己突破技术前沿。

## 模块四：蓝图复刻

### 最值得学习的创新点

不是技术创新，是 **"竞品自我设限 = 你的护城河"** 的商业逻辑。

Janitor AI 的核心创新是发现了一个极其稳定的市场空白：大公司因为品牌/监管/道德原因主动放弃的高付费意愿用户群。这个空白不会被填补——因为填补它的条件恰恰是大公司不愿承担的品牌成本。

**这个模式成功的关键假设**：大公司永远不会做 NSFW。这在可预见的未来是成立的（Google/Meta/OpenAI/Anthropic 的品牌不允许）。

### 可复制的战术剧本

**剧本一："抢禁区"——从竞品的自我设限中找市场**

| 步骤 | 行动 |
|------|------|
| 1 | 找到一个主流产品主动排除的用户群/场景 |
| 2 | 验证这个被排除的需求是否真实且有付费意愿 |
| 3 | 用最简 MVP 服务这个需求（Janitor AI 的 MVP 就是 Character.ai + 无审核） |
| 4 | 竞品的每一次审核收紧都是你的增长催化剂 |

适用场景：任何有"道德审查 → 用户流失"现象的品类。AI 写作（主流工具禁止生成暴力/色情内容）、AI 图像（DALL-E 和 Midjourney 限制多）、AI 视频（所有平台都有严格审核）。

**剧本二："濒死求生 → 技术自主"——被断供后自建能力**

| 步骤 | 行动 |
|------|------|
| 1 | 初期用别人的 API 快速验证需求（不要过早自建） |
| 2 | 如果被断供（如 OpenAI C&D），立刻启动自建计划 |
| 3 | 同时开放"用户自带 Key"作为过渡方案（空间换时间） |
| 4 | 自建模型上线后，"免费 + 无限制"成为核心差异化 |

适用场景：任何依赖第三方 API 且可能违反其内容政策的产品。

**剧本三："70% 女性"——找到被忽视的人群**

| 步骤 | 行动 |
|------|------|
| 1 | 分析你的产品的真实用户构成（不要假设，要测量） |
| 2 | 如果发现非预期人群（如"NSFW 平台"的 70% 女性用户），深入理解她们的真实 JTBD |
| 3 | 围绕这个人群的需求重新设计产品（角色创作工具、故事连续性、情感深度） |
| 4 | 在营销叙事中突出这个非预期用户群（"这不是你以为的那种平台"） |

适用场景：任何用户构成与"直觉预期"不一致的产品。

### 终极复盘

如果 Jan Zoltkowski 第一天就知道所有事：

1. **不用 OpenAI API**——直接从开源模型起步，避免被封禁的风险。但现实是 2023-06 的开源模型还不够好，GPT API 是唯一能支撑流畅对话的选择。OpenAI C&D 是"不可避免的痛苦"。
2. **从第一天就做移动端 PWA**——Web 流量的 18 分钟会话时长极高，移动端 PWA（不通过 App Store）可以进一步提升粘性。
3. **更早开放 Pro 订阅**——第一周就有 100 万用户，但付费功能到 2024 年才上线，错失了早期高付费意愿的窗口。

**三个启示**：
- 不要等"所有条件都准备好"——先用别人的 API 跑起来，被封了再自建
- "被禁止"是最好的广告——OpenAI C&D 被 Reddit/Discord 传开后，反而让更多人知道了 Janitor AI
- 低调是 NSFW 产品的生存策略——不做品牌 → 不引来监管 → 不需要花钱维护公共关系 → 更多利润

## "70% 女性" 的深层分析

这是整个 Janitor AI 案例中最值得深挖的数据点。

**行业刻板印象**："AI 色情 = 男性用户"
**现实**：70% 女性用户，18 分钟会话，12+ 页面深度

**为什么？**

1. **同人创作文化的延伸**：AO3（Archive of Our Own）有 4500 万用户，80%+ 女性，以 BL/言情/角色扮演为主。Janitor AI 是这个文化从"写作"到"交互"的自然演化——从"我写角色"变成"我和角色对话"。

2. **Character.ai 审核的性别化影响**：Character.ai 的 NSFW 审核不成比例地打击女性用户——因为女性用户的主流用例（浪漫/情感/亲密关系对话）比男性用户的主流用例（动作/冒险）更容易触发内容安全过滤。结果：Character.ai 的审核把最有价值的用户群（高粘性、高创作力的女性用户）推给了 Janitor AI。

3. **付费心理学**：女性在"体验消费"上的支出倾向高于男性。Janitor AI 的订阅不是为"功能"付费，而是为"不被打断的情感体验"付费——这和为 Netflix 或 Kindle Unlimited 付费的心理学是同一类。

**商业含义**：如果 Janitor AI 想大幅提升付费率，最高效的方式不是"加更多功能"，而是"围绕女性创作者的需求深化产品"——更好的角色创作工具、更长的记忆、故事线连续性、角色之间的关系网络。

## Mars 视角

Janitor AI 的故事其实很简单但很聪明：在别人看到风险的地方看到机会。Character.ai 不让你做的事，恰恰是需求最迫切的。这就是"抢禁区"的全部逻辑。

但反直觉的部分不是商业模式本身，而是**70% 女性用户**这个数据。整个业界以为 NSFW AI = 男性色情需求，现实直接打脸了。真实的 JTBD 是交互式创意写作——女性创作者在 AO3 和 Wattpad 上创作 BL/言情已经有十几年的传统，Janitor AI 只是让这个创作过程从"写小说"升级到了"和角色对话"。这个用户群的粘性，其实不亚于任何娱乐产品。所以付费意愿就来了：她们不是在买"色情"，而是在买"不被打断的创作自由"。

距钱距离上，Janitor AI 其实比大多数 AI 应用都近。消息限制是自然的 Freemium 转化点，付费心理学很清晰——你限制了他们最爱的事，他们就付钱解锁。这比"说服用户为了效率而付费"直接多了。

最有趣的是被 OpenAI 禁止函那一幕。很多人会说"这是灭顶之灾"，但 Jan Zoltkowski 的做法是立刻自建模型。约束逼出的创新，让 Janitor AI 从 API 附庸变成了独立公司。这个反向逻辑和 DeepSeek 的芯片制裁一样——**被禁止反而成了差异化机会**。

监管风险是真实的，但历史上成人内容行业每次被打击都找到了新形式存活。Janitor AI 的问题不是存活，而是能否在保持"自由度"的同时符合监管要求。
