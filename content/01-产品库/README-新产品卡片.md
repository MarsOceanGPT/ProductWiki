## 核心洞察总结

### 竞争维度的分化
- **Kling** = 本地化优先（vs 国际竞品的通用性）
- **Pixverse** = 专业工作流（vs 易用性导向）
- **Higgsfield** = 社交美学（vs 保真度导向）
- **SeaArt** = 创意社区（vs 功能完整度）
- **VivaCut** = 专业功能（vs 大众易用）
- **Pixelcut** = 电商垂直（vs 通用工具）
- **OurDream** = UGC驱动（vs 官方内容）
- **Edits** = 政策机遇（vs 技术优势）

### 商业模式的多元化
- **B2B为主**（Pixverse、Pixelcut）→ 高ARPU、低用户量
- **社区变现**（SeaArt、OurDream）→ 创作者激励的正反馈
- **完全免费**（Edits）→ 生态内变现
- **混合模式**（Kling、VivaCut）→ 既面向消费者也面向企业

### 出海路径的差异
- **快手内部孵化**（Kling）→ 资源密集、快速商业化
- **创业融资驱动**（Pixverse、Higgsfield）→ 融资加速、国际化
- **社区口碑**（SeaArt、VivaCut）→ 长期积累、有机增长
- **大厂生态**（Edits）→ 政策+资源双驱动
