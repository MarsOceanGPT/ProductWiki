# 银河通用机器人（Galbot）

> 成立不足 3 年，融资 25 亿元破中国具身智能纪录。斯坦福博士 + ABB 工程师的组合，用双臂轮式机器人卡位工业赛道。

## 基本面

| 字段 | 内容 |
|------|------|
| **核心产品** | Galbot G1 双臂人形机器人 |
| **形态特征** | 轮式底盘 + 双臂（可折叠躯体） |
| **首发日期** | 2024 年 6 月 |
| **设计理念** | "能做活"的机器人 = 实际应用 > 概念演示 |
| **融资总额** | 25 亿元（2026 年 3 月最新轮） |
| **融资历程** | 种子轮（1个月内）→ 天使轮 7 亿（2024.6）→ 战略轮 5 亿（2024.11）→ 新一轮 25 亿（2026.3） |
| **融资方** | 国家大基金、上汽恒旭、IDG、经纬、蓝驰、红杉 |
| **现状** | 小批量交付中，工业应用试点 |
| **市场地位** | 中国具身智能融资总额第一 |

**王鹤 - CTO & 创始人**

- 出身：清华电子系（2014）→ 斯坦福 PhD（2021）
- 经历：斯坦福博士后 → 北京大学助理教授
- 身份：北大-银河通用具身智能联合实验室主任、北京智源人工智能研究院具身智能研究中心主任
- 核心能力：多模态大模型、具身智能、强化学习

**关键基因**：王鹤的强项是"AI + 机器人的交集"。

```
大模型时代的具身智能 = 多模态感知 + 实时决策 + 动作执行
王鹤的研究方向正好是这个三角形的顶点
```

**姚腾洲 - 联合创始人**

- 经历：ABB 机器人集团研发中心
- 专长：工业机器人系统集成、生产工程化

**这个组合的妙处**：

```
王鹤：AI 侧（控制决策）
姚腾洲：工业侧（系统实现）
→ 既不是"纸上谈兵的 AI"，也不是"无脑硬件堆砌"
```

这个速度**只有两个赛道能做到**：

2. **具身智能**（2024-2025 的"现在就能用"效应）

## 二、成长旅程

### 2.1 市场机会：具身智能的"应用窗口"

**过去的困境**：

```
2020 年：人形机器人很酷，但没人知道怎么用
2021 年：机器人成本还是 100 万起，没有商业场景
2022 年：深度学习进步快，但工程应用滞后
```

**现在的变化**（2024-2025）：

```
大模型普及 → AI 芯片成本下降 → 轻量化模型可以在机器人上跑 → "能干活的机器人"成为可能
```

银河通用卡到的就是这个窗口。

**反共识判断**：

大家都在讨论"何时人形机器人会普及"，但银河通用问的是：**"现在需要什么样的机器人才能赚钱？"**

答案是：**工业级、可以干活、成本相对可控的双臂机器人**。

### 2.2 产品：Galbot G1 的设计哲学

#### 为什么是"轮式双臂"而不是"四足"或"纯人形"？

```
四足（如宇树 Go2）：
  强项 → 可以登楼梯、通过复杂地形
  弱项 → 没有臂力，无法做精细操作

轮式人形（如 Galbot G1）：
  强项 → 平面上速度快、操作灵活、双臂力量强
  弱项 → 无法登楼梯（但 95% 工业场景不需要）

四足 vs 轮式：在工业环保、物流、制造的场景里，轮式的投入产出比更高
```

#### Galbot G1 的核心规格

| 指标 | G1 | 行业参考 |
|------|-----|---------|
| **形态** | 轮式底盘 + 双臂可折叠躯体 | 独特设计 |
| **身高** | 约 1.7m（折叠后更紧凑） | Tesla Optimus 1.73m |
| **臂力** | 单臂 25kg 负载（双臂 50kg） | Boston Spot ~10kg |
| **续航** | 待补充 | 通常 2-4 小时 |
| **速度** | 轮式移动时 1-2 m/s | 快速部署 |
| **自由度** | 双臂 40+ DoF | 业界主流 |
| **定价** | 预售价待补充 | 参考 Figure AI ~300 万人民币 |

**最聪明的设计**：身体可折叠。

```
物流仓库场景：
需要在狭窄通道、货架之间工作
→ Galbot 的可折叠躯体能压低高度
→ 避免撞毁货架
```

这个细节看似不起眼，但在"工业化应用"的层面上，**比 Boston Dynamics 的高端设计还要实用**。

### 2.3 应用验证：从零售走向物流

**已落地的场景**（截至 2024 年底）：

```
零售门店 → 库存盘点、商品整理、客户交互
物流仓库 → 分拣辅助、货物搬运、路径规划
制造工厂 → 装配辅助、质量检测、工件搬运
```

**关键数据**：

- 2024 年 6 月发布 → 2024 年底已有多家零售/物流企业试用
- 单机作业效率：人工 1 人 vs 机器人可部分替代（预计 50-70%）
- ROI 周期：2-3 年（对工业应用来说可接受）

### 2.4 融资加速度：国家大基金的出手

**2026 年 3 月 25 亿元融资的信号**：

```
国家大基金（国内最大的产业基金）首次重点投资具身智能
→ 说明"具身智能即将进入产业化阶段"
→ 政府层面已判定：这不是实验室产品，而是"有产业前景的领域"
```

对标：

```
国家大基金在 2014-2016 年重点投资芯片 → 今天中国有海思、紫光
国家大基金在 2023-2024 年重点投资 AI 芯片 → 今年会继续加码
国家大基金在 2026 年重点投资具身智能 → 预示 3-5 年内这会成为产业
```

### 2.5 商业模式：B2B 定制 + 云端管理

**模式**：

```
企业采购 → Galbot G1 基础平台 → 定制化开发 → 部署运维 → 按机器人小时数计费
```

**费用构成**：

```
硬件成本：50-100 万元/台（估）
集成服务：30-50 万元/台
年度维保：5-10 万元/台
运维收入：按小时或产出分成
```

**盈利模型**：

- **前期**（2024-2025）：靠硬件销售 + 集成费
- **中期**（2025-2027）：硬件销售降低，运维收入占比上升
- **后期**（2027+）：纯软件和服务收入（高毛利）

## 三、战略框架

### 3.1 技术赌注：多模态大模型 + 实时控制

银河通用的技术堆栈：

```
感知层：多模态输入（视觉 + 触觉 + 听觉）
推理层：大模型 in-domain 推理（轻量化）
执行层：实时控制 + 动作库
```

与宇树的对比：

| 维度 | 宇树（控制算法）| 银河通用（多模态 AI）|
|-----|---------|----------|
| **技术核心** | PID 控制 + 强化学习 | 多模态大模型 + 决策引擎 |
| **研发周期** | 10 年积累（大疆） | 3 年积累（学术) |
| **可复制性** | 中（控制是通用的） | 低（每个应用都需微调） |
| **融资速度** | 快（商业清晰） | 更快（概念吸引投资） |

### 3.2 竞争格局：卡位"性价比人形"

| 对手 | 定位 | 优势 | 劣势 | vs Galbot |
|-----|------|------|------|----------|
| **Figure AI** | "终极人形"（高端） | 技术完整，融资充足 | 成本高、交付遥远 | Galbot 是"现在能用" |
| **Tesla Optimus** | "汽车公司的人形" | 特斯拉生态、目标成本 20 万 | 优先级低，交付遥遥无期 | Galbot 已在试点 |
| **宇树 H1** | "工业级人形"（性价比） | Go2 已有落地应用 | 人形经验不足 | Galbot 从人形起家 |
| **高进机器人** | "国产人形"（概念） | 融资热点 | 没有明确应用 | Galbot 已验证应用 |

**Galbot 的竞争优势**：

```
不是技术最强（Figure AI 更强）
不是成本最低（Tesla 目标最低）
而是"现在就能用 + 成本相对可控"的最优组合
```

### 3.3 核心优势：学术 + 工业的完美配合

```
王鹤（学术侧）→ 能设计前沿的多模态架构
姚腾洲（工业侧）→ 能把实验室产品工程化
```

这个优势很难复制，因为它需要：

1. 顶级学术背景（斯坦福 + 北大）
2. 工业系统经验（ABB 级别的公司）
3. 强大融资背书（红杉、蓝驰、国家大基金）

### 3.4 生态位定位

```
上游：大模型（接驳 OpenAI、国内开源模型）
  ↑
【银河通用：多模态推理 + 具身化执行】← 价值最高
  ↓
下游：工业应用方（零售、物流、制造）
```

这个位置最优的原因：**既不赌大模型前沿，也不赌应用创新，只需要把"大模型往机器人躯体上装"做好**。

## 四、蓝图复刻

### 4.1 融资驱动的增长

```
融资 → 产能扩张 → 应用落地 → 数据积累 → 模型迭代 → 融资
```

这个循环银河通用已经走了 3 次（2024-2026）。

**对其他初创的启示**：

融资不是为了"活命"，而是为了"加速应用验证"。每一轮融资都要有明确的应用节点。

### 4.2 产品分化战略

现在只有 G1（通用双臂）。

未来可能：

```
G1 Pro（重载版）→ 制造工厂
G1 Lite（轻载版）→ 零售门店
G2（人形升级）→ 服务业
```

**启示**：同一个平台，多个SKU，覆盖不同市场。

### 4.3 反面教材：融资漂亮但应用空缺

很多具身智能公司融资金额大，但没有明确的应用场景。

银河通用的差异：**融资 + 应用同步**。

### 4.4 三个启示

**启示 1：融资速度取决于"距钱的距离"**

银河通用融资快的根本原因：工业应用已可见（2-3 年 ROI），而不是赌 5-10 年后的消费品。

**启示 2：联合创始人的互补性决定成败**

学术 + 工业的结合，比"全是学术"或"全是工业"强 10 倍。

**启示 3：国家大基金的出手是行业信号**

当政府投资基金开始重点配置一个新赛道，说明这个赛道已经进入"产业化前夜"。

## 五、Mars 视角

**反共识的成立时间**：

```
2023 年 6 月成立 → 为什么"现在"？

2022 年底：ChatGPT 发布，大模型时代开始
2023 年底：轻量化开源模型可以在边缘设备跑（Llama 等）
2024 年初：AI 芯片成本开始快速下降
2024 年中：工业企业开始寻找 AI 应用（需求侧拉动）
→ 2024 年中后期：具身智能的"应用窗口"打开
```

王鹤和姚腾洲选择在 2023 年 6 月创业，**说明他们提前 6-9 个月看到了这个窗口**。

**融资速度的真实逻辑**：

```
2024 年 6 月融资 7 亿（天使轮最大单笔）
→ 原因不是"融资好谈"，而是"工业试点反馈超预期好"
→ VC 看到试点数据后，才愿意投这么多
```

对比同期的通用人形机器人：

```
Figure AI：融资快（OpenAI 背书）
银河通用：融资也快（应用落地）
→ 前者赌"概念"，后者赌"应用"
→ 后者的融资可持续性更强
```

**距钱距离的最终判断**：

```
Galbot G1：距钱 0-2 年（已在工业试点）
运维收入：距钱 2-3 年（需要规模化)
消费级应用：距钱 5+ 年（还太远）
```

银河通用的融资速度快的原因：**距钱最近的赛道融资最快**。

**反向思考**：

市场在争论"谁的人形机器人技术最强"，但银河通用问的是"谁的人形机器人能最快赚钱"。

答案很可能是：不是最强的，而是最实用的。
