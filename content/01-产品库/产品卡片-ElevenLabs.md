# ElevenLabs

> 一句话：让 AI 说话像真人一样——从配音、克隆到音乐，做"所有声音 AI"的基础设施。出现在每一版 a16z 榜单上。

---

## 一、基本面

ElevenLabs 由两个波兰高中同学于 2022 年 4 月创立。Piotr Dąbkowski（CEO/CTO）是前 Google ML 工程师，牛津本科+剑桥硕士，研究成果发表在 NeurIPS；Mati Staniszewski 是前 Palantir 部署策略师，帝国理工数学一等荣誉学位，曾在 BlackRock 做产品。两人小时候看波兰电影，受不了单人解说员的单调配音——这个童年困扰成了创业的起点。

融资：$2M Pre-seed（2023.1）→ $19M A 轮（2023.6，a16z 领投，$1 亿估值）→ $80M B 轮（2024.1，a16z+Sequoia 联合领投，$11 亿估值）→ $180M C 轮（2025.1，$33 亿）→ $500M D 轮（2026.2，Sequoia 领投，$110 亿）。总融资 $7.8 亿+。

关键指标：$3.3 亿 ARR（2025 年 12 月），已实现运营盈利。60%+ 的财富 500 强在用。600-700 名员工，分布在 6 个大洲。毛利率 70-80%。

ARR 增长曲线堪称教科书：$0（2022）→ $460 万（2023 年底）→ $2500 万（2024 年初）→ $9000 万（2024.10）→ $1 亿（2025.4）→ $2 亿（2025.9）→ $3.3 亿（2025.12）。3 年从零到 $3.3 亿且盈利。

## 二、成长旅程

### 2.1 怎么找到这个机会的

两个波兰小孩看电影时的困扰：波兰电影配音只用一个人，不区分角色性别、情感、语气。他们意识到——**让声音听起来像真人，不是技术问题，是没人认真做这件事**。

当时的 TTS（Siri、Alexa）听起来像机器人。不是因为技术不可能做好，而是大厂把语音当附属功能而非核心产品。ElevenLabs 的赌注：**专注做一件事——让 AI 声音不可区分于真人**。用神经网络捕捉人声中的"不完美"——停顿、笑声、情绪起伏、填充词——正是这些"不完美"让声音听起来像人。

相关打法：[[打开价格门槛新市场]]、[[从工具到工人]]

### 2.2 产品怎么设计的

产品从单点（TTS）扩展为完整音频平台，目前有 14 个产品：

核心层：文本转语音（TTS）、语音克隆（即时克隆+专业克隆）、AI 配音工作室（29 语言，保留原声特征）、音效生成、语音转文字（Scribe）

扩展层：AI 音乐生成、对话式 AI / Voice Agents（ElevenAgents）、语音变换器、语音隔离器

消费层：ElevenReader（有声书 App，2024.6 上线）

平台层：Voice Library 市场（10000+ 声音，创作者可变现）、API

关键设计决策：**研究层+应用层垂直整合**。他们不只做应用，底层模型也是自研的。这和只调 API 的 AI 创业公司完全不同——他们有 7 名专职音频 AI 研究员，专门优化声音质量。

相关打法：[[生成式界面]]

### 2.3 怎么验证的（MVP）

2022 年全年在 stealth 模式做研发，专注于一件事：让合成语音听起来像真人。不做功能堆叠，先把核心做到极致。

2023 年 1 月公测：输入文字 → 生成逼真语音，或上传 30 秒录音 → 即时克隆你的声音。体验极其简洁。

**5 个月内达到 100 万注册用户**，几乎没有市场推广——全靠创作者社区口碑（YouTuber、播客主、有声书作者、独立游戏开发者）。免费层（10000 字符/月）消除了试用摩擦。

核心 wow moment：用户第一次听到自己声音的 AI 克隆版——那个"这就是我的声音！"的惊讶感。

相关打法：[[服务先行]]

### 2.4 怎么切入市场的（PMF）

和很多 B2B SaaS 不同，ElevenLabs **不是从企业开始的，是从创作者开始的**：

第一圈：内容创作者（YouTuber、播客主、有声书作者、独立游戏开发者）——他们迫切需要低成本高质量的配音。

第二圈：开发者——通过 API 把 ElevenLabs 集成到自己的产品中（游戏、App、客服机器人）。Meta、Epic Games、Salesforce、MasterClass 都是 API 客户。

第三圈：企业——华盛顿邮报、TIME、HarperCollins、大西洋月刊、纽约客等媒体用它做多语言内容。

这个从创作者 → 开发者 → 企业的渗透路径和 Cursor 类似——**自下而上，先赢个人再赢组织**。

PMF 证据：5 个月 100 万用户，全靠有机增长。发布 4 个月就能以 $1 亿估值融 A 轮。

相关打法：[[迫切刚需]]、[[别无选择]]

### 2.5 怎么增长的

**病毒传播是最大引擎**。创作者用 ElevenLabs 生成的内容本身就是产品广告——一个 YouTuber 用 AI 配音的视频被百万人看到，每个观众都可能成为潜在用户。

2023 年初的 deepfake 争议（有人用它克隆 Emma Watson 的声音读希特勒的书）反而成了增长催化剂——媒体大量报道 → 知名度暴涨 → 用户涌入试用。

配音工作室的 demo 视频也很病毒——展示英语电影用原声特征配成其他语言的效果，在创作者社区疯传。

**a16z 的持续背书**：ElevenLabs 出现在自 2023 年 9 月以来的每一版 a16z Top 100 榜单上。这在创作者/开发者社区是极强的信誉信号。

相关打法：[[病毒传播-产品即内容]]、[[借势崛起]]

### 2.6 怎么赚钱的

多层定价，覆盖从个人到企业的全谱段：

- Free（$0/月）：10,000 字符
- Starter（$5/月）：30,000 字符 + 商用许可
- Creator（$11/月）：100,000 字符 + 专业语音克隆
- Pro（$99/月）：500,000 字符 + API 访问
- Scale（$330/月）：百万级信用额度 + 多席位
- Business（$1,320/月）：大批量 + 专属支持
- Enterprise：自定义（SLA、SSO、HIPAA）

收入结构约 60% API/企业、40% 创作者/消费者。

**Voice Library 市场变现**是亮点：声音创作者上传声音，每生成 1000 字符收 $0.03-0.20。已向创作者累计支付超过 $500 万。有人每月被动收入 $300+。这创造了网络效应——更多创作者上传好声音 → 声音库质量更高 → 更多用户使用 → 更多收入给创作者。

相关打法：[[按访问-订阅]]、[[按消耗-请求数]]

### 2.7 壁垒在哪

ElevenLabs 的壁垒比 Cursor 和 Perplexity 都要强。原因：

**1. 语音质量是专业壁垒**。图像生成（DALL-E、Midjourney）可以被 LLM 大厂顺手做了，因为共享 transformer 架构。但语音合成需要完全不同的领域专长——音频信号处理、神经声码器、韵律建模、说话人分离。大厂把语音当副产品，ElevenLabs 把它当唯一产品。MOS（平均意见分数）评测中，ElevenLabs 在情感复杂场景拿到 4.54 分，超过 Google Cloud TTS。

**2. 研究+应用垂直整合**。自研模型而非调 API。7 名专职音频 AI 研究员。从研究想法到产品功能可以在几周内完成。

**3. Voice Library 网络效应**。创作者的声音和收入绑定在平台上，切换成本高。

**4. 企业信任积累**。60%+ 财富 500 强。华盛顿邮报、TIME、HarperCollins 等建立了工作流整合。

最大风险：如果 OpenAI/Google 某天决定把语音质量做到 ElevenLabs 的水平并免费/低价打包进 ChatGPT/Gemini。但目前来看，大厂优化的是速度和成本，不是极致质量——这给了 ElevenLabs 持续的差异化窗口。

## 三、战略框架

### 3.1 时代红利（Why Now）

四波红利交汇：（1）神经声码器成熟（HiFi-GAN 2020，让高保真合成变得可行）；（2）Transformer 架构在语音领域的应用（捕捉长距离韵律和情感依赖）；（3）创作者经济爆发（YouTube、播客、有声书市场 2020-2022 指数增长）；（4）ChatGPT 时刻让 AI 生成内容被文化接受。

如果早两年——神经声码器不够成熟，创作者经济没到临界点。如果晚两年——大厂可能已经把语音做成附属功能。2022 年是"技术可行+市场需要+大厂还没注意到"的最佳窗口。

### 3.2 核心优势

配置论：ElevenLabs 选择的竞争维度不是"谁的 TTS 更便宜"（大厂必赢），而是**"谁的声音质量更真实"**。这是一个大厂不愿意在上面投入足够资源的维度，因为对 Google/OpenAI 来说，语音只是千分之一的功能，但对 ElevenLabs 来说，这是全部。

Cursor for X 评估：配音工作流复杂度高（选声音、调情感、多语言、剪辑对齐），重复劳动多（每个视频都要配，每种语言都要做），反馈机制清晰（听一下就知道好不好）。完美契合。

距钱距离：近。创作者用它配音 → 发布内容 → 直接变现（YouTube 广告收入、有声书版税）。企业用它本地化内容 → 进入新市场 → 直接带来收入。不是"提升效率"这种模糊的价值——是直接创造可交付物。

### 3.3 生态位

**中间件层**——这是 ElevenLabs 最有意思的定位。它不是纯应用层（不只给终端用户用），也不是基础设施层。它是"AI 语音的中间件"——上面跑着各种应用（Reader App、配音工作室），下面被各种开发者通过 API 集成（Meta、Epic Games、Salesforce）。

这个"工头层"位置在 Mars 的产业分层框架里恰好是最有价值的：控制了 AI 语音能力的分发，上下游都依赖它。

AI 定价象限：高自主性（AI 独立完成语音生成）× 高可归因性（产出的语音直接可听可评估）= 按使用量收费的天花板高，按结果收费也有空间（比如按配音完成的小时数计费）。

反脆弱：下行风险是大厂语音质量追赶+打包免费。上行空间是成为"所有声音 AI"的基础设施层（从语音扩展到音乐、音效、对话式 AI）。杠铃策略——保守端是企业合同+创作者生态锁定（稳定收入），激进端是 Voice Agent 和音乐生成（全新市场）。

## 四、其他

**Deepfake 悖论**：语音克隆安全问题本来可能毁掉公司——4Chan 用户克隆名人声音制造不当内容。但 ElevenLabs 的应对反而把"bug 变成 feature"：被迫实施的安全机制（身份验证、Voice Captcha、名人声音屏蔽）成了进入壁垒——小竞争对手没有资源做合规，大企业客户（华盛顿邮报、Disney 级别）反而更信任有安全机制的产品。

**已经盈利**：在 AI 创业公司普遍烧钱的时代，ElevenLabs 在 2024 年底实现运营盈利，同时还保持 260%+ YoY 增长。这在同行中极其罕见——说明单位经济学从一开始就是健康的。

**ElevenReader 的意外增长**：2024 年 6 月推出的有声书 App，让任何人可以把书、PDF、文章变成 AI 朗读。这从一个 B2B 语音工具公司延伸出了一个 C 端产品——类似 Discord 从游戏通信扩展到泛社交。甚至增加了自出版功能——作者可以零成本把书变成有声书。有潜力成为"有声书领域的 Spotify"。

**Voice Library 经济学**：声音创作者被动收入最高每月 $300+，平台已累计向创作者支付超 $500 万。这个市场模式和 Spotify/YouTube 的创作者经济类似——平台的价值随创作者增多而增加。

**文字转音乐**：2024 年中宣布，2025 年 7 月公开。从语音扩展到音乐生成——这意味着 ElevenLabs 的野心不是"做最好的 TTS"，而是**拥有所有声音 AI**。

## Mars 视角

说实话，ElevenLabs 成功的地方不在"声音质量"，尽管这是它的技术优势。本质上它赢在了一个被所有人忽视的维度——**情绪带宽**。文本转语音听起来像机器人，不只是因为声学质量差，而是因为丧失了人类交流中的大量信息：停顿、语气起伏、笑声、情感。ElevenLabs 通过捕捉这些"不完美"，让声音有了温度。这反而告诉我们：AI 生成内容的瓶颈，往往不是逼真度（逼真≠自然），而是那些让人感到"真实存在"的细节。

有意思的是，ElevenLabs 做的不只是"更好的 TTS"，而是在改变"声音"这个维度的定义。从"信息载体"升级到"情感载体"。这个升维带来的直接后果是：Voice Library 市场的创作者网络效应。不是"谁的模型更强"，而是"谁能让创作者在这里赚到钱"。这是把工具变成了经济平台——每个声音都是一个微型创业者。

但也别被这个成功迷惑了。ElevenLabs 现在的护城河看起来坚固（财富 500 强采用、创作者锁定、自研模型），实际上是"技术沙漏"结构——上面有大量应用方（Media、游戏、企业），下面有一个自研模型，中间被 API 收费卡位。问题是：一旦 OpenAI 或 Google 把语音质量做到相同水平，这个沙漏就会被打穿。反而现在最值钱的不是语音技术本身，而是"Voice Library 生态"——数十亿小时的语音数据，这才是真护城河。

关键观察：ElevenLabs 已经盈利的事实，在 AI 创业公司里极其罕见。这说明什么？说明"距钱距离近"的产品确实不一样——创作者用它直接赚钱，企业用它直接变现内容，用户愿意付费。这个商业模式的健康度，比规模更重要。
